    • 6待你拍板的两处细节

    1点「数据库」节点，主区该给什么？

    你的原话是「点击多个数据库，tab 都不会增加对应数据 tab」，所以这里有两种理解。点选项直接看上方效果图变化。

    库数据 tab（我的建议）对象清单 + 每表行数/大小 + 前 100 行预览；库内双击表再进表 tab。
    库查询 tab每个库一个独立 SQL 草稿页（更接近 dbx 的 OpenConsole），不展示数据。

    2每个 tab 是否要有独立撤销栈？

    现状：编辑器实体全页唯一（db.rs:1390-1397 注释写明），撤销栈跨 tab 共享，切 tab 可能退回上一个 tab 的文本。

    每 tab 独立编辑器（我的建议）每 tab 一个 EditorState，撤销栈、折叠状态、光标位置互不串；内存成本 = tab 数 × 编辑器。
    继续共享单编辑器改动小，但撤销栈串台问题保留，只对 SQL 文本做快照切换。
