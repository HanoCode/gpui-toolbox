> 本文是四份评审的**唯一收敛稿**，不再新增分析，只做三件事：
> ① 把四份里互相矛盾/说过头的地方**裁决掉**；② 把 74 条待办压成**一条执行序列**；

>
> 四份原文（保留细节与证据链，本文不重复）：

## 1. 五句话结论

1. **方向是对的，不要换栈。** 驱动系统 `ssh(1)` 换来的是「用户已有的全部登录能力 + fail-closed」，
   这是本仓最大的资产。自研协议栈（russh）要半年，换不来对等收益（`duck-ssh/src/lib.rs:1-40`）。
2. **三个「静默失效」比缺功能贵得多**：改了连接参数不生效（ControlMaster）、网络黑洞时 SFTP 永久转圈、
   按键没反应也不报错（键盘只挂画布）。这三类用户不会报 bug，只会觉得「这软件不稳」。
3. **中文错位是唯一「每个中文用户第一分钟就能看见」的 bug**，优先级高于所有美化
   （实测 13px 下每汉字右移 5.17px）。
4. **缺的不是功能，是两条缝**：连接没有所有权（谁开、谁关、几条通道），字节没有管道
   （编码/换行/登录脚本/askpass 无处可插）。补完这两条，后面每个功能都是「往栈里 push 一个」。
5. **UI 的病根是三条习惯**：每个区域都要自带一行标题（吃掉 128px）、一行只承载一个动作
   （第二个动作只能记快捷键）、一件事说三遍（工具条/状态栏/标签点）。

## 3. 根因：六笔欠账 + 一个原点

| ID | 欠账 | 现在是什么 | 一次能解决什么 |
| --- | --- | --- | --- |
| **S1** | **连接所有权** | 复用靠 `ControlPath` 哈希（只 hash destination/port/identity），没人负责关（`target.rs:523`、`conn.rs:322`） | 参数失效、转发不可见、SFTP 无法复用、残留 master |
| **S2** | **字节缝** | vte 解析在 alacritty `EventLoop` 线程内，`SessionEvent` 只有 `Wakeup`，**没有 `Output(bytes)`**（`duck-term/src/session.rs:176-198`） | 编码、换行翻译、登录脚本、交互式 askpass、ZMODEM、hex、录制——七件一起 |
| **S3** | **渲染原点** | 行文本「逐格拼 String → 整行自然排版」，而光标/选区按 `列号×格宽` 定位 | 中文错位、组合字符、emoji、IME 候选窗、搜索命中 |
| **S4** | **设置广播** | 设置写 `kv`，活会话建页面时读一次（`terminal/helpers.rs:9` 注释自认） | 三份真源、改完要重开、`ui_scale` 不联动 |
| **S5** | **入口与键盘上下文** | 入口 = 14 字段表单；键位全挂 `"Terminal"` 且只挂画布 | 死键、`⌘T` 语义错、临时连一台要建档 |
| **S6** | **界面颗粒度** | `render_*.rs` 是「一个函数返回一整块」，行只有一个 `on_click` | 组件不能复用、第二个动作只能右键/记键 |

> **为什么先补 S1/S2 而不是先补功能**：这两个是「加功能的地方」。现在每加一个能力都要在
> `target.rs` / `conn.rs` / `terminal_canvas.rs` 三处各补一次判断（转发、健康检查、录制都是这样），
> 补完还互不知道对方存在。S2 更极端——**没有位置**，不是「没实现」。

## 7. 不做清单（四份合并）

| 不做 | 理由 |
| --- | --- |
| 自研 SSH 协议栈 / 换 russh | 现有路线 = 用户全部登录能力 + fail-closed；只在 SFTP 一处需要协议能力，局部引入 |
| 私有 `known_hosts`（Tabby 的做法） | 两套 TOFU 真相是债；读写系统库 + 显式「接受并保存」更正确 |
| 内置代码编辑器 / IDE 工作区 | 与工具箱定位冲突；最多只读预览 |
| tmux 控制模式 / Mosh / 串口 / RDP-VNC | 各自一个子系统 |
| 云端同步连接档案 | 密钥托管问题 |
| 「自动连接上次会话」/「自动展开分组」 | 默认不替用户做有副作用的决定（与「界面禁演示数据」同一纪律） |
| 主机密钥校验开关 | 安全闸门不做成可关项 |
| SGR 5/6 闪烁、sixel/kitty graphics、字距任意调节、GPU shader | 上游多数也不做，或与逐簇定位冲突 |
| 每连接覆盖全部设置项 | 只覆盖四项，否则设置项爆炸 |
| 每档案一条全局快捷键（照搬 Tabby） | 槽位投影替代 |
